# DRILL #9 소년 상하좌우 이동 및 방향 바꾸기

## 실행

```
python move_character_with_key.py
```

필요한 리소스(`TUK_GROUND.png`, `animation_sheet.png`)는 같은 폴더에 있고, 상대경로로 읽는다.

## 조작

| 키 | 동작 |
| --- | --- |
| ← → ↑ ↓ | 소년 이동 (두 키를 함께 누르면 대각선 이동) |
| ESC | 종료 |

## 구현 내용

- 방향키를 누르는 동안 상하좌우로 이동하고, 키를 떼면 멈춘다.
- 멈춰 있으면 바라보는 방향의 IDLE 애니메이션을 재생한다.
- 좌우로 이동하면 그 방향의 달리기 애니메이션을 재생하고, 위아래로 이동할 때는 기존 방향을 유지한다.
- 화면 경계에 닿으면 더 이상 나아가지 않는다.

자세한 요구사항과 검증 기준은 [PRD.md](PRD.md)에 있다.
